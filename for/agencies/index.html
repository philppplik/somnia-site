Somnia / For agencies

Concept in development. Phase 0 prototype is live.

For agencies and teams, later.

Agencies often split design and code across separate tools. Somnia aims to let both work on the same plain files. Team features come late in the plan, so this page is mostly about direction.

Open the Phase 0 prototypeHonest status

Status. Somnia is in development. Only the Phase 0 browser prototype exists today. The native desktop app, the AI layer, framework support, the extension SDK and any download or purchase are not available yet.

The short version

Nothing team-related exists yet. The prototype is a single-user browser tool. What exists is the foundation that makes team work possible later: your project is plain files, so Git and any editor already work with it.

What is not decided

The pricing page lists open questions, including the seat threshold for SSO. Review workflows with clients and real-time collaboration are not part of what Somnia has committed to.

What to use now

Keep your current design and development tools. If you want to see where Somnia goes, try the prototype on a small internal page and read the roadmap.

FAQ

Can my team use Somnia today?

No. Only a single-user browser prototype exists. Team features are planned for later phases.

How much will the Team plan cost?

The working plan is $19 per user per month. It is not final and nothing is for sale yet.

Does Somnia replace Figma for designers?

No. See the Figma comparison. Somnia edits the real page, not a mockup.
