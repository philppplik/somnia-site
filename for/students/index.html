Somnia / For students

Concept in development. Phase 0 prototype is live.

For students, learn on real code.

Somnia shows your page and its code side by side, so you can click something and see what changed. That part works in the prototype today. Student pricing is only a plan.

Open the Phase 0 prototypeHonest status

Status. Somnia is in development. Only the Phase 0 browser prototype exists today. The native desktop app, the AI layer, framework support, the extension SDK and any download or purchase are not available yet.

The short version

The prototype is free to try in a browser, with no account. It is a useful place to see how a visual change turns into HTML and CSS. It is not a full course or a finished tool.

What works today

  • Split view with code and a live canvas, and one shared undo history.
  • Click, drag and edit text in place, with a layers tree.
  • Desktop, tablet and mobile views. Smaller-size changes are written as readable media queries.
  • Multi-file projects and ZIP export, so you can keep your work.

Be realistic

Somnia is early. Browser support for opening local folders is limited to Chromium-based browsers. For a structured course, you will still want a proper learning resource alongside it.

FAQ

Is Somnia free for students?

The plan includes a free tier and a student program. Neither is final, and nothing is for sale yet. The prototype is free to try now.

Do I need an account for the prototype?

No.

Will I learn real HTML and CSS?

The output is plain HTML and CSS you can read and edit, which is the point of the split view.
