Somnia / For freelancers

Concept in development. Phase 0 prototype is live.

For freelancers, planned.

Somnia is designed around problems freelance designers describe: per-site platform fees, code you cannot hand over cleanly, and being tied to one host. Most of the answer is still a plan.

Open the Phase 0 prototypeHonest status

Status. Somnia is in development. Only the Phase 0 browser prototype exists today. The native desktop app, the AI layer, framework support, the extension SDK and any download or purchase are not available yet.

The short version

The idea is simple. You build client sites visually, the output is plain HTML and CSS in a folder, and you deploy to whichever host the client uses. Only the editing basics exist today, in a browser prototype.

Planned pricing, briefly

The working plan is a free tier, a $79 one-time Individual license and an optional Pro subscription for cloud and hosted AI features. It is a plan, not an offer. See planned pricing for the open questions.

What it will not do

Somnia will not host sites or run a CMS for your clients. If a client needs editing by non-technical staff, pair it with a CMS or a hosted platform. See the Webflow comparison.

Should you use it on client work now?

No. It is a prototype. Try it on a personal page, and keep client projects in a tool you rely on.

FAQ

Can I use Somnia for paid client work today?

Not recommended. Only the Phase 0 prototype exists, and there is no download.

Will one license cover all my clients?

That is the plan: the Individual license is meant for one person, with no per-site fee. Pricing is not final.

Does Somnia host client sites?

No. You deploy to the host you choose. Deploy tools are planned for Phase 3.
