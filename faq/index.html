Open the Phase 0 prototypeHonest status

Status. Somnia is in development. Only the Phase 0 browser prototype exists today. The native desktop app, the AI layer, framework support, the extension SDK and any download or purchase are not available yet.

What is Somnia?

Somnia is a visual web design studio that is currently in development. It renders your page on a real browser canvas, writes clean HTML and CSS that you own, and is planned to include an AI layer that sees your design. A browser prototype (Phase 0) is available today.

Is Somnia a Dreamweaver alternative?

That is the goal. Somnia targets people who liked the split code and design view of Dreamweaver and want a fast, modern tool that keeps plain HTML and CSS as the real product. It is not a finished replacement yet: the native desktop app does not exist and only the browser prototype is available.

Can I download Somnia?

Not yet. There is no installer, no price and no license key. You can open the Phase 0 prototype in a Chromium, Firefox or Safari browser without an account. Opening and saving local folders works in Chromium browsers.

How much will Somnia cost?

Nothing is for sale. The current plan is a free tier, a $79 one-time Individual license, an optional Pro subscription at $12 per month or $120 per year, Team at $19 per user per month and custom Enterprise pricing. This is a working plan and can change.

Does Somnia lock my work into a project format?

No. The design principle is plain HTML, CSS and JS files on your disk that you can export or deploy anywhere.

Does Somnia have AI features?

Not yet. An AI layer called Oneiroi is planned for Phase 3. It is meant to see the canvas, show every change as a diff before it is applied, and work with your own API key or local models.

Does Somnia support Tailwind, Bootstrap, React or Vue?

Not yet. Bootstrap and Tailwind are planned for Phase 2, and React, Vue and Svelte for Phase 3.

Which browsers does the prototype run in?

Chrome, Edge, Firefox and Safari. Opening and saving local folders works in Chromium-based browsers only.

Can I use Somnia with my existing Dreamweaver site?

Plain HTML, CSS and JS files open in the prototype. Dreamweaver templates and library items are not supported yet. Work on a copy.

Who is building Somnia?

Philipp Paulik (philipp-paulik.de).

What is planned next?

Phase 1 is a core visual editor for building a simple page, as a closed alpha. After that come Tailwind and Bootstrap support, an AI layer with diff review, an accessibility audit, a deploy panel and finally native installers. Dates are not promised.
