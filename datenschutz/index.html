Datenschutzerklärung

Datenschutzerklärung.

Was Somnia mit deinen Daten macht, in klaren Worten. Kurz: Sie bleiben auf deinem Rechner.

Kurz gesagt. Somnia arbeitet mit Dateien auf deinem eigenen Rechner. Es gibt kein Konto, keine Analyse und kein Tracking, und der Entwickler erhält weder deine Dateien noch Daten darüber, wie du die App nutzt. Die einzige Netzwerkanfrage der App ist eine optionale Prüfung auf neue Versionen bei GitHub.

Stand: 5. Oktober 2026.

Verantwortlicher

Somnia wird von Philipp Paulik entwickelt (der "Entwickler"). Kontakt für Datenschutzfragen: philipp.l.paulik@gmail.com.

Was die Somnia-Desktop-App mit deinen Daten macht

Deine Projektdateien bleiben auf deinem Gerät

Somnia öffnet einen Ordner oder eine Datei, die du auswählst, und speichert Änderungen an derselben Stelle auf deiner Festplatte. HTML, CSS, JavaScript und Bilder werden nirgendwohin hochgeladen. Der Entwickler betreibt keinen Server, der sie empfangen würde.

Lokal von der App gespeicherte Daten

  • Wiederherstellungs-Snapshots. Beim Bearbeiten legt die App ungespeicherte Änderungen in einem lokalen Wiederherstellungsordner (recovery-v1) im App-Datenordner deines Windows-Benutzerprofils ab, damit Arbeit nach einem Absturz wiederhergestellt werden kann. Ein Snapshot wird nach dem Speichern der Datei entfernt.
  • Einstellungen und gespeicherte Elemente. Layout, Theme, Tastenkürzel, deine Komponenten-Bibliothek und deine Erweiterungsauswahl liegen im lokalen Speicher der App auf deinem Gerät.

Nichts davon wird an den Entwickler oder an andere gesendet. Zum Entfernen lösche deine Projektordner und deinstalliere die App. Die Deinstallation entfernt die Programmdateien; den lokalen App-Datenordner kannst du von Hand löschen, wenn du auch Wiederherstellungs-Snapshots und Einstellungen entfernen möchtest.

Keine Konten, keine Analyse, kein Tracking

Somnia hat keine Anmeldung, keine Telemetrie, keine Absturzberichte, keine Werbung und keine Analyse durch Dritte. Die App erhebt keine personenbezogenen Daten über dich.

Die einzige Netzwerkanfrage: Update-Prüfung

Beim Start kann die App bei GitHub nachfragen, ob eine neuere Version existiert. Dafür ruft sie die öffentliche Release-Liste von github.com/philppplik/somnia über api.github.com ab. Die Anfrage enthält kein Konto, keine Projektdaten und keine Kennung aus der App. Wie bei jeder Webanfrage erhält GitHub deine IP-Adresse und übliche technische Anfragedaten und verarbeitet sie nach der GitHub-Datenschutzerklärung. Du kannst diese Prüfung in den Einstellungen ausschalten. Wenn du ein Update installierst, lädt die App es auf dieselbe Weise von GitHub herunter.

Installierst du Somnia aus dem Microsoft Store, übernimmt der Microsoft Store die App-Updates und seine eigene Datenerhebung nach der Microsoft-Datenschutzerklärung. Der Entwickler erhält diese Daten nicht.

Vorschau und Erweiterungen

Die Live-Vorschau läuft in einem isolierten Frame ohne Netzwerkzugriff. Skripte deines Projekts laufen darin erst, nachdem du das für ein Projekt erlaubt hast. Erweiterungen laufen lokal und können nach dem heutigen Stand der App nicht auf das Netzwerk zugreifen.

Diese Website

Diese Seite (somnia.philipp-paulik.de) ist eine statische Seite auf GitHub Pages. Sie nutzt keine Cookies, keine Analyse und keine Skripte von Dritten. GitHub als Hoster kann technische Daten wie deine IP-Adresse in Server-Logs verarbeiten. Der Browser-Prototyp auf der Startseite läuft komplett in deinem Browser; Dateien, die du darin öffnest, werden nicht hochgeladen.

Deine Rechte

Da der Entwickler über die App keine personenbezogenen Daten erhebt, gibt es auf seiner Seite normalerweise nichts zu beauskunften, zu berichtigen oder zu löschen. Wenn du in der EU bist und glaubst, dass der Entwickler Daten über dich hat, schreib an die Adresse oben. Du hast außerdem das Recht, dich bei deiner Datenschutz-Aufsichtsbehörde zu beschweren.

Kinder

Somnia ist ein allgemeines Werkzeug für Webdesign und richtet sich nicht an Kinder. Es erhebt keine Daten von irgendjemandem.

Änderungen

Wenn die App Daten künftig anders behandelt, zum Beispiel durch eine optionale Online-Funktion, wird diese Seite vor dem Release aktualisiert und die Änderung hier aufgeführt. Die aktuelle Fassung findest du immer unter somnia.philipp-paulik.de/datenschutz/.
