Working in the prototype

Code and design, in sync.

Split view puts code on one side and the canvas on the other. Type in the code and the canvas updates. Drag, drop and style on the canvas and the file updates. One shared undo history covers both.

  • CodeMirror 6 editor for HTML, CSS and JS
  • Click, drag, reorder, duplicate and edit text in place
  • Layers tree with drag and drop
Working in the prototype

Responsive by design, not by accident.

Switch to tablet or mobile and every change you make is written as a real media query. The desktop style stays untouched, and undo removes it again.

  • Desktop 1280, tablet 820, mobile 390
  • Overrides saved as readable CSS in your file
  • Margin and padding shown right on the canvas
Planned

An AI that sees your canvas.

Oneiroi, the AI layer, will not only read code. It will see hierarchy, spacing and color. Select an element and ask for a change, then review every edit as a diff before it lands. Bring your own key or run local models.

  • Diff review for every change, accept or reject per hunk
  • Accessibility audit with suggested fixes
  • Your keys, your data, a fully offline mode
Planned

Frameworks as first-class citizens.

Vanilla HTML first, then Tailwind and Bootstrap with real component libraries, then React and Vue. The output stays idiomatic code you would be happy to commit.

  • Semantic HTML, class-based CSS
  • No vendor runtime injected into your site
  • Deploy by ZIP, SFTP or GitHub Pages

Honest status

FAQ

Questions about Somnia and Dreamweaver alternatives.

What is Somnia?

Somnia is a visual web design studio that is currently in development. It renders your page on a real browser canvas, writes clean HTML and CSS that you own, and is planned to include an AI layer that sees your design. A browser prototype (Phase 0) is available today.

Is Somnia a Dreamweaver alternative?

That is the goal. Somnia targets people who liked the split code and design view of Dreamweaver and want a fast, modern tool that keeps plain HTML and CSS as the real product. It is not a finished replacement yet: the native desktop app does not exist and only the browser prototype is available.

Can I download Somnia?

Not yet. There is no installer, no price and no license key. You can open the Phase 0 prototype in a Chromium, Firefox or Safari browser without an account. Opening and saving local folders works in Chromium browsers.

Does Somnia lock my work into a project format?

No. The design principle is plain HTML, CSS and JS files on your disk that you can export or deploy anywhere.

What is planned next?

Phase 1 is a core visual editor for building a simple page, as a closed alpha. After that come Tailwind and Bootstrap support, an AI layer with diff review, an accessibility audit, a deploy panel, and finally native installers.
