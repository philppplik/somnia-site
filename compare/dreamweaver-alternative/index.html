Somnia / Dreamweaver alternative

Concept in development. Phase 0 prototype is live.

A Dreamweaver alternative, in development.

Somnia is aimed at people who liked the split code and design view of Dreamweaver and want a fast, modern editor that keeps plain HTML and CSS as the real product. It is not a finished replacement.

Open the Phase 0 prototypeHonest status

Status. Somnia is in development. Only the Phase 0 browser prototype exists today. The native desktop app, the AI layer, framework support, the extension SDK and any download or purchase are not available yet.

The short version

If you want a lightweight visual editor for plain HTML and CSS and can wait, Somnia is worth watching. If you need a finished tool today, Dreamweaver or another current editor is the safer choice.

When to stay with Dreamweaver

Stay if you maintain older server-side projects (for example classic ASP.NET or PHP-heavy sites), depend on features Somnia does not plan to cover, or need a production-ready tool today. Somnia is not that yet.

FAQ

Is Somnia a replacement for Dreamweaver?

Not yet. It is a stated goal. Today only a browser prototype exists, with no desktop app, no download and no price.

Can Somnia open my Dreamweaver sites?

Plain HTML and CSS files open in the prototype. Dreamweaver-specific features such as templates and library items are planned as conversion helpers and are not built. See the migration page.

Is Somnia free?

The prototype is free. The planned product has a free tier and paid plans, none of which are available yet.
