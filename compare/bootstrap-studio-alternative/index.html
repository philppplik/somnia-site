Concept in development. Phase 0 prototype is live.

A Bootstrap Studio alternative, on paper.

Bootstrap Studio is a desktop app built around Bootstrap. Somnia plans Bootstrap 5 and Tailwind CSS 4 support, but not before Phase 2. Today it does neither.

Open the Phase 0 prototypeHonest status

Status. Somnia is in development. Only the Phase 0 browser prototype exists today. The native desktop app, the AI layer, framework support, the extension SDK and any download or purchase are not available yet.

The short version

If your work is Bootstrap sites and you want a visual tool now, Bootstrap Studio exists and Somnia does not yet cover that. Somnia is worth watching if you want one editor for plain HTML, Bootstrap and Tailwind, with files you own.

What the Somnia plan covers for frameworks

The roadmap lists Bootstrap 5 components, Tailwind CSS 4 detection with class autocomplete, a visual grid and flex editor, an asset manager and starter templates under Phase 2, planned as a public beta. React, Vue and Svelte come later, in Phase 3, and may be reduced in scope. None of this is built.

When to stay with Bootstrap Studio

If you build Bootstrap sites today, use a tool that supports it today.

FAQ

Does Somnia support Bootstrap today?

No. Bootstrap 5 support is planned for Phase 2. You can open a plain HTML file that links Bootstrap and edit the markup, but there is no component library.

Will Somnia support Tailwind?

Tailwind CSS 4 detection and class tools are planned for Phase 2.

When is Phase 2?

No dates are promised. Phase 1 is a closed alpha first.
