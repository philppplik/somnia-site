Somnia / Compare / Pinegrow alternative

Concept in development. Phase 0 prototype is live.

A Pinegrow alternative, still early.

Pinegrow is an established desktop editor that already works with local files. Somnia aims at a similar idea with a faster, simpler feel. It is far less finished, and this page says so.

Open the Phase 0 prototypeHonest status

Status. Somnia is in development. Only the Phase 0 browser prototype exists today. The native desktop app, the AI layer, framework support, the extension SDK and any download or purchase are not available yet.

The short version

Pinegrow is a working desktop product that edits local HTML and CSS today. Somnia has a browser prototype only. If you need a visual editor for local files now, evaluate Pinegrow first. Watch Somnia if its planned design (split view, real media queries, an AI that sees the canvas) matches what you want later.

Where Somnia aims to differ

  • One shared undo history across code and canvas.
  • Tablet and mobile changes saved as readable media queries, with desktop styles left untouched.
  • Design targets for a small, fast native app (installer under 10 MB, cold start under 800 ms). These are targets, not measurements.

When to stay with Pinegrow

If you need a complete visual editor for local sites today, Pinegrow is the safer choice. Somnia cannot be installed yet.

FAQ

Does Somnia work with local files like Pinegrow?

Yes, by design. The prototype opens and saves a local folder in Chromium-based browsers. The native app is planned.

Is there a Pinegrow importer?

No. Plain HTML, CSS and JS files open in the prototype. Product-specific project data is not supported.

Is Somnia a perpetual license?

The plan includes a one-time Individual license plus a free tier. It is not final and nothing is for sale yet.
