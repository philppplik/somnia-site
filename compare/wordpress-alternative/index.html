Somnia / WordPress alternative

Concept in development. Phase 0 prototype is live.

A WordPress alternative, for static sites.

WordPress is a content management system. Somnia is a design editor. For a small site with few changes, static files can be simpler. For a site with many editors and frequent content, WordPress is built for that.

Open the Phase 0 prototypeHonest status

Status. Somnia is in development. Only the Phase 0 browser prototype exists today. The native desktop app, the AI layer, framework support, the extension SDK and any download or purchase are not available yet.

The short version

Somnia may suit a designer who builds small static sites by hand and wants a visual editor for them. It does not replace a CMS.

When to stay with WordPress

Stay with WordPress if several people edit content regularly, you need plugins such as shops or memberships, or you need a CMS back end. Somnia will not provide those.

FAQ

Does Somnia work with WordPress?

Not today. A WordPress theme export has been considered but is not planned for any specific phase.

Is a static site better than WordPress?

Neither is better in general. Static files are simple, fast and cheap to host. WordPress is better when non-developers need to edit content often.
