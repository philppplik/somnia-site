Somnia / Compare / VS Code alternative

Concept in development. Phase 0 prototype is live.

VS Code, plus a canvas.

VS Code is a general-purpose code editor. Somnia is a visual web design tool with a code view. They overlap on HTML and CSS only, and many people would use both.

Open the Phase 0 prototypeHonest status

Status. Somnia is in development. Only the Phase 0 browser prototype exists today. The native desktop app, the AI layer, framework support, the extension SDK and any download or purchase are not available yet.

The short version

Somnia is not meant to replace VS Code for application development. It is meant for the case where you want to see and click the page you are editing, and still end up with plain files. If you are happiest in code, you may not need it.

How they can work together

Because Somnia keeps your project as plain files, you can open the same folder in VS Code. There is no project format that blocks this. In the prototype, opening and saving a local folder works in Chromium-based browsers. The native app is planned.

When to stay with VS Code only

Back-end work, apps, big codebases and anything outside HTML and CSS belong in a code editor. Somnia does not aim to be one.

FAQ

Is Somnia a code editor?

It has one, but the point is the visual canvas with a code view. Do not expect VS Code features such as a terminal or an extension marketplace yet.

Can I edit the same project in both?

That is the design: plain files on disk, no project format. Work on a copy while Somnia is a prototype.

Will Somnia have VS Code extensions?

No. Somnia plans its own extension SDK in Phase 4.
