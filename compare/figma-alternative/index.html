Somnia / Figma

Concept in development. Phase 0 prototype is live.

Not a Figma replacement. A different step.

Figma is a design and prototyping tool. Somnia edits the real page in a browser canvas and writes the code. Many people will use both.

Open the Phase 0 prototypeHonest status

Status. Somnia is in development. Only the Phase 0 browser prototype exists today. The native desktop app, the AI layer, framework support, the extension SDK and any download or purchase are not available yet.

The short version

If you already design in Figma and then build by hand, Somnia may become a faster place to build the page. Today it is an early prototype.

When to stay with Figma

Stay with Figma for UI exploration, design systems, vector work, prototypes and team review. Somnia does not aim to cover those.

FAQ

Can Somnia import Figma files?

No. There is no importer and none is planned for any specific phase.

Is Somnia a design tool or a code editor?

Both, in a narrow sense: it edits a real web page visually and in code. It is not a general design tool.
