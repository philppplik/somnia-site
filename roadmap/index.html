Somnia / Roadmap

Concept in development. Phase 0 prototype is live.

The roadmap, without dates.

Somnia is built in phases. Phase 0 is live as a browser prototype. Everything after it is a plan, and dates are not promised.

Open the Phase 0 prototypeHonest status

Status. Somnia is in development. Only the Phase 0 browser prototype exists today. The native desktop app, the AI layer, framework support, the extension SDK and any download or purchase are not available yet.

Phases at a glance

PhaseNameStatusWhat it covers
Phase 0FoundationLive as a browser prototypeSplit view, canvas, layers tree, responsive views, multi-file projects, ZIP export
Phase 1Core visual editorPlannedClosed alpha. Style manager, resize handles, color picker, reliable autosave, more complete drag and drop.
Phase 2Frameworks and polishPlannedPublic beta. Bootstrap 5, Tailwind CSS 4, grid and flex controls, asset manager, templates.
Phase 3Professional featuresPlannedOneiroi AI layer, Git panel, deploy panel, accessibility audit, React/Vue/Svelte (may shrink).
Phase 4 and 5Extensions and launchPlannedExtension SDK and marketplace, native installers, launch.

How to read this

The roadmap is a working plan, and it has changed before. If a feature is not marked as working in the prototype, it does not exist. Design targets such as an installer under 10 MB, cold start under 800 ms and idle memory under 80 MB are targets, not measurements.

What is not on the roadmap

  • A project format that locks in your work.
  • Hosting or a CMS. Somnia is an editor.

Where to look next

The features page lists each feature with its status. Oneiroi has its own page. Planned pricing and the FAQ cover the rest.

FAQ

Is there a release date?

No. Dates are not promised.

The Phase 0 browser prototype only. There is no installer and nothing to buy.

Will the order of phases change?

It can. This page will be updated when it does.
