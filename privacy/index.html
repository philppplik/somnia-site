Privacy Policy

Privacy policy.

What Somnia does with your data, in plain words. Short answer: it stays on your computer.

Short version. Somnia works on files on your own computer. It has no account, no analytics and no tracking, and the developer does not receive your files or any data about how you use the app. The only network request the app makes is an optional check for new versions on GitHub.

Last updated: October 5, 2026.

Who is responsible

Somnia is developed by Philipp Paulik (the "developer"). Contact for privacy questions: philipp.l.paulik@gmail.com.

What the Somnia desktop app does with your data

Your project files stay on your device

Somnia opens a folder or file that you choose and saves changes back to the same place on your disk. Your HTML, CSS, JavaScript and images are not uploaded anywhere. The developer has no server that receives them.

Data stored locally by the app

  • Recovery snapshots. While you edit, the app keeps unsaved changes in a local recovery folder (recovery-v1) inside the app data folder of your Windows user profile, so work can be restored after a crash. A snapshot is removed after you save the file.
  • Settings and saved items. Layout, theme, keyboard shortcuts, your saved component library and your extension choices are kept in the app's local storage on your device.

None of this is sent to the developer or to anyone else. To remove it, delete your project folders and uninstall the app. Uninstalling the app removes its program files; the local app data folder can be deleted by hand if you want to remove recovery snapshots and settings as well.

No accounts, no analytics, no tracking

Somnia has no sign-in, no telemetry, no crash reporting, no advertising and no third-party analytics. The app does not collect personal data about you.

The only network request: update check

When the app starts, it can ask GitHub whether a newer release exists by requesting the public release list of github.com/philppplik/somnia from api.github.com. The request carries no account, no project data and no identifier from the app. As with any web request, GitHub receives your IP address and standard technical request data, and handles it under the GitHub Privacy Statement. You can turn this check off in Settings. If you choose to install an update, the app downloads it from GitHub the same way.

If you install Somnia from the Microsoft Store, the Microsoft Store handles app updates and its own data collection under the Microsoft Privacy Statement. The developer does not receive that data.

Preview and extensions

The live preview runs in an isolated frame that has no network access. Scripts from your project run in it only after you allow that for a project. Extensions run locally and, as the app is built today, cannot reach the network.

This website

This site (somnia.philipp-paulik.de) is a static site hosted on GitHub Pages. It does not use cookies, analytics or third-party scripts. GitHub, as the host, may process technical data such as your IP address in server logs. The browser prototype on the home page runs entirely in your browser; the files you open in it are not uploaded.

Your rights

Because the developer does not collect personal data through the app, there is normally nothing to access, correct or delete on his side. If you are in the EU or UK and think the developer holds data about you, write to the address above and you will get an answer. You also have the right to complain to your local data protection authority.

Children

Somnia is a general-purpose web design tool and is not directed at children. It does not collect data from anyone.

Changes

If the app starts to handle data differently, for example by adding an optional online feature, this page will be updated before that release, and the change will be listed here. The current version of this page is always at somnia.philipp-paulik.de/privacy/.
