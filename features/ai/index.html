Somnia / Features / Oneiroi AI

Concept in development. Phase 0 prototype is live.

Oneiroi, planned and not built.

Oneiroi is the name of Somnia's planned AI layer. The idea is an assistant that sees your design, not only your code, and asks before it changes anything. Today it does not exist.

Open the Phase 0 prototypeHonest status

Status. Somnia is in development. Only the Phase 0 browser prototype exists today. The native desktop app, the AI layer, framework support, the extension SDK and any download or purchase are not available yet.

What it is meant to do

IdeaWhat it meansStatus
Canvas-aware requestsSelect an element on the canvas and ask for a change. The AI knows which element you mean and its current styles.Planned, Phase 3
Diff reviewEvery change is shown as a diff you accept or reject before it is applied. By default nothing is written without confirmation.Planned, Phase 3
Your own key or local modelsBring your own API key for cloud models, or use local models such as Ollama.Planned, Phase 3
Multi-step edits with undoBounded multi-step actions with visible progress and an undo-all.Planned, Phase 3
Privacy modesNo code telemetry without explicit opt-in.Planned, Phase 3
Inline suggestionsAutocomplete-style ghost text in the code view.Planned, Phase 3

What exists today

Nothing. The Phase 0 prototype has no AI features. The free tier is planned to include a small monthly allowance of AI requests, and the optional Pro plan is planned to include hosted AI credits. Both are plans, not offers. See planned pricing.

Why it is described this way

Many AI design tools exist or are launching. Somnia does not claim to be better at the AI part. The planned difference is where the AI sits: in a local editor that keeps plain files, with changes you review.

No claims about models

Which models will be supported, what they cost and how well they work is not decided or tested. Nothing on this page is a benchmark.

FAQ

Can I try Oneiroi?

No. It is planned for Phase 3 and has not been built.

Will it send my code to a cloud service?

The plan is bring-your-own-key for cloud models, local models as an option, and no telemetry without opt-in. None of this is built yet, so treat it as a design goal.

Will AI be required?

No. The editor is meant to work fully without it.
