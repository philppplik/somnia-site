Features, honestly marked.

Every feature of Somnia is labeled as working in the Phase 0 prototype or planned for a later phase. If it is not labeled as working, it does not exist yet.

Open the Phase 0 prototypeHonest status

Status. Somnia is in development. Only the Phase 0 browser prototype exists today. The native desktop app, the AI layer, framework support, the extension SDK and any download or purchase are not available yet.

Feature list

Code and design in sync

Working in the prototype  Phase 0

Split view with the code on one side and a canvas that renders your real page in a browser on the other. Edits in either place update the other, with one shared undo history. The editor is CodeMirror 6.

Click, drag and edit on the canvas

Working in the prototype  Phase 0

Select elements, reorder them, duplicate them, edit text in place, and use a layers tree with drag and drop. Margin and padding are shown on the canvas.

Responsive editing as real media queries

Working in the prototype  Phase 0

Switch between desktop (1280), tablet (820) and mobile (390). Changes made at a smaller size are written as readable media queries in your CSS file. Desktop styles stay untouched.

Multi-file projects and local folders

Working in the prototype  Phase 0

Multi-file projects, preview, ZIP export and a command palette. Opening and saving a local folder works in Chromium-based browsers only.

Core visual editor for simple pages

Planned  Phase 1

A full style manager, resize handles, color picker, reliable autosave and more complete drag and drop. Phase 1 is planned as a closed alpha.

Bootstrap and Tailwind support

Planned  Phase 2

Bootstrap 5 components and Tailwind CSS 4 detection, class autocomplete and a visual class builder. Also grid and flex controls, an asset manager and starter templates. Phase 2 is planned as a public beta.

Oneiroi, the AI layer

Planned  Phase 3

An AI that sees the canvas, not only the code. Select an element, ask for a change, and review the result as a diff before it is applied. Planned options: your own API key, or local models. Not built yet.

Accessibility audit

Planned  Phase 3

A live accessibility overlay based on axe-core.

Git panel and deploy panel

Planned  Phase 3

Visual diff, commit, push and pull, plus FTP/SFTP and deploys to services such as Netlify, Vercel, GitHub Pages and Cloudflare Pages.

React, Vue and Svelte

Planned  Phase 3

Component trees and props panels for common frameworks. This is the most ambitious part of the plan and may be reduced in scope.

Extension SDK and marketplace

Planned  Phase 4

A public SDK and a marketplace for extensions. Not started.

Native desktop app

Planned  Phase 0 to 5

A small desktop app built on Tauri and Rust. Design targets (not measured yet): installer under 10 MB, cold start under 800 ms, idle memory under 80 MB.

What Somnia will not do

  • Lock your work into a project format. The principle is plain HTML, CSS and JS files on your disk.
  • Replace a CMS or a hosting platform. Somnia is an editor.
