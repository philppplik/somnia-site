Moving from Dreamweaver, carefully.

Plain HTML, CSS and JS files open in the prototype. Dreamweaver-specific features do not. This page lists both.

Open the Phase 0 prototypeHonest status

Status. Somnia is in development. Only the Phase 0 browser prototype exists today. The native desktop app, the AI layer, framework support, the extension SDK and any download or purchase are not available yet.

What works today

  • Open a local folder of plain HTML, CSS and JS files in a Chromium-based browser (Chrome, Edge) and save changes back to the same files.
  • Edit in code view, design view or split view.
  • Tablet and mobile edits are written as readable media queries.
  • Export the project as a ZIP.

What is planned but not built

  • Recognizing Dreamweaver template files (.dwt) and suggesting a conversion.
  • Cleaning up inline styles.
  • Importing FTP and site settings.
  • An optional Dreamweaver-style keyboard shortcut set.

What will not be supported

  • Server-side language features of Dreamweaver, for example running or previewing PHP or ASP.NET.
  • Dreamweaver's proprietary site management features.

A careful way to try it

  1. Copy your site to a new folder. Do not point the prototype at your only copy.
  2. Open the copy in the prototype using a Chromium-based browser.
  3. Check pages in split view and compare them with the original in your browser.
  4. Report problems. It is a prototype and will have bugs.

See also the Dreamweaver comparison.

Migration FAQ

Can I open my Dreamweaver site in Somnia?

Yes for plain HTML, CSS and JS files. In the Phase 0 prototype you can open a local folder in a Chromium-based browser, edit, and save back. Dreamweaver-specific features are not supported.

Does Somnia support Dreamweaver templates?

Not yet. Recognizing .dwt templates and suggesting a conversion is a planned helper. Library items (.lbi) are only an idea.

Will my files be changed or locked in?

Somnia has no project format. Back up your site before opening it in any new tool, including the prototype.
